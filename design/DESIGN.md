# Safion Design System

## Typography
- **Primary Font**: Space Grotesk
- **Weights**: 
  - Light (300): Hero subtext, captions
  - Regular (400): Body copy, standard UI text
  - Medium (500): UI labels, tabs, wordmark
  - Bold (700): Headlines, display text
- **Wordmark Style**: Space Grotesk 500, ALL CAPS, 0.30em letter-spacing.

## Color Palette
- **Signal Orange** (`#F54F00`): Primary / Alert / Active. **Rule:** Use ONLY for active detection nodes, live alerts, and primary CTAs. Do not use for decoration.
- **Void** (`#09090E`): Main page/app background.
- **Node Inactive** (`#181826`): Inactive states, deep secondary backgrounds, cards.
- **Boundary** (`#1C1C2E`): Borders, structural dividers, strokes.
- **Frost** (`#EDEDF4`): Primary Text. **Rule:** Never use pure white (`#FFFFFF`).

## Component Styles
- **Geometry**: "Squircle" methodology. UI elements (cards, buttons, icons) should use a border-radius equal to roughly 40% of their shortest side to maintain the brand's shape language.
- **Layout**: Dark mode default. Strict orthogonal grids.

## Brand Voice
- **Tone**: Precise, authoritative, vigilant.
- **Rule**: Never use emojis, exclamation points, or passive voice. Use concrete, unambiguous language (e.g., "Flagged 3 violations in Zone B").
